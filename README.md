# El Flappy Bird Aka Kiro

Initial folder containing support resources for the Flappy Kiro game.

## Example UI

![Flappy Kiro UI](img/example-ui.png)

## How to Play

### Getting Started

1. Open `index.html` in any modern web browser.
2. The start screen will appear with the title **Flappy Kiro** and a prompt.
3. Press **Space**, click the canvas, or tap the screen to begin.

### Controls

| Input | Action |
| --- | --- |
| `Space` key | Flap (jump upward) |
| Mouse click | Flap (jump upward) |
| Touch tap | Flap (jump upward) |

### Objective

Guide the ghost through the gaps between the green pipes. Each pipe pair you successfully clear adds **1 point** to your score, shown at the top of the screen.
